3D TIC TAC TOE
Ongoing

So, this was a course project for my PSP course.

The main idea of the game was to play Tic Tac Toe on a 4 x 4 x 4 matrix cube, where the rules are similar to the normal game, except that we have to match four Xs or Os in a row, column, or diagonal.

To build this game, I used the Goat itself... Drumroll... RAYLIB!

Yes, Raylib is one of the craziest game libraries out there. If you know C or C++, you're good to go. The whole game was built in just 300 lines of code. JUST 300.

Well, now I'm actually going to finish this and turn it into a proper game using all the concepts of OOP. Yep, it's another course project, this time for my OOP course.

The repository link added above is for the previous version, which was written in C + Raylib. Since the OOP changes are still ongoing, I haven't updated the repository yet.
