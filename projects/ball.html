Ball Balancing Game (on a budget)
15th May 2026

As the project title suggests, this is a ball-balancing game that was built on a budget.

We made a remote that syncs with the plate to balance the ball. The longer the ball stays balanced, the higher the score.

It's that simple.

We used two basic **SG90 servo motors** connected to an **Arduino Uno** to control the plates. The plates receive signals from an **ESP32 module (the remote)**, which is connected to an **MPU6050 module**, a gyroscope and accelerometer.

This was a simple project, but it took a lot of time to build.

Since this was a team project, my friend actually built the main hardware model. Props to **Aranya**!
