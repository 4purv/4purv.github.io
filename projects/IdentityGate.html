Identity Gate
20th june 2026

This was a big project that took up most of my time throughout the semester.

The main idea of this project was to build a facial recognition system for a residential society to determine whether the person driving a resident's vehicle is authorized to drive it or not. If the person is authorized, the gates would open. If not, a notification containing a photo of the driver would be sent to the respective owner of the vehicle.

Now, to actually identify which vehicle we're talking about, we took inspiration from an already existing technology called ANPR (Automatic Number Plate Recognition).

We didn't actually use this technology, though, as the cameras and software required were expensive. I also didn't want to build an entire database for vehicle recognition, so we decided to focus specifically on the facial recognition part.

Now, for the actual system architecture:

I used YOLOv8 to detect faces and FaceNet through DeepFace for facial recognition. I then used Flask with ngrok to send requests from the main system to a PWA (Progressive Web App) for notifications, which was also hosted through ngrok.

The database is stored locally. If a driver's face is not recognized, their photo is temporarily stored in a file and sent as a request to the vehicle owner's device. However, the photo is also retained on the main PC.
